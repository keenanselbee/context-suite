Context Suite third-party software
=================================

This software is based in part on the work of the Independent JPEG Group.

Context Suite uses Magick.NET / Magick.Native and ImageMagick with JPEG,
PNG, WebP, Little CMS, libxml2 and zlib components. The complete selected
engine notices and the WebP patent grant accompany this file in
Magick.NET.Notice.txt. Keep both files with every binary distribution.

The native engine is a custom Q16 x64 build with a reduced dependency/link
configuration. It is not the unmodified upstream native bundle. Codec
algorithms are unchanged. Source revisions, build overlay and component
inventory are documented in tools/curated-engine in the source repository.

The DDS worker bridge links the CPU-only
DirectXTex library (MIT), pinned to revision
5ddca91f9ad07308957bd9d4dffe204914a98acb. Its complete license accompanies
this file as DirectXTex.License.txt. Context Suite's bridge is separate
authored code; it does not change ownership of the upstream library.

Lossless PNG optimization uses the separately pinned upstream oxipng 10.1.0
Windows x64 executable. Its MIT license accompanies this file as
Oxipng.License.txt; keep that file with the executable. The product's private
validation and process adapter are separate authored code.

Microsoft .NET host components are generated by the installed SDK. Its
license and third-party notices accompany this file as DotNet.License.txt
and DotNet.ThirdPartyNotices.txt. The desktop runtime is a separately
installed prerequisite; this development output does not bundle it.
Microsoft C++ runtime code and Windows system components are subject to
their applicable Microsoft terms. Build tools are not included.

Third-party components retain their own licenses. This notice does not
license Context Suite source or proprietary application implementations,
or certify commercial redistribution/patent clearance.
