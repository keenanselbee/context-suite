Context Suite HEIC/AVIF decoder candidate
========================================

This optional decoder uses libheif 1.23.4 and libde265 1.1.3, whose library
sources identify GNU Lesser General Public License version 3 or later terms.
Their complete original COPYING documents, including LGPL and GPL texts,
accompany this local review bundle. Original source archives and the exact
local error-propagation patch are retained in the source-review kit.

Local change, 2026-09-16: the libheif libde265 adapter propagates failed NAL-push
results, retaining security-limit and allocation failures. No decoder limit or
media transformation is changed. libde265 source remains unchanged.

libheif statically links the selected AOM 3.15.0 artifact, built from revision
79de389e4abced53cb6e85b7574826dbc227cd9c of ImageMagick's AOM source repository.
The original AOM BSD notice, authors, patent license, supplier notice and source
archive are retained. Collected source notices are deliberately inclusive and
do not assert that every archived file is linked into this decoder.

The private Context Suite bridge is a separate DLL and its source is absent from
this kit. This notice does not license private application source or establish
terms for the public build tools. Upstream contributors do not endorse Context
Suite. Microsoft compiler/runtime use and distribution require their own review.
